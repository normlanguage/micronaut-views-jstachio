# Micronaut Views JStachio

[English](README.md) | [简体中文](README.zh-CN.md)

The [`module.norm`](micronaut/views/jstachio/module.norm) declaration publishes `micronaut.views.jstachio@2`, binds `io.micronaut.views:micronaut-views-jstachio:6.2.0`, exports `jstachio.annotation@2`, and depends on `jstachio.processor@2`.

[Samples](samples/README.md) render and escape a typed HTML page through a loopback server.
